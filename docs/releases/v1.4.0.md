# Takip Atlası 1.4.0

## Bulunan sorun
- Eski `accounts/current_user` sorguları web oturumunda hesap JSON'u yerine ana sayfaya yönleniyordu; detay sorguları 429 alıyordu.
- PC'de liste okunmuş olsa da profil fotoğrafı ve hesap sayaçları karta bağlanmamıştı.

## Düzeltme ve yöntem
- PC tarayıcısının çalışan web profil yanıtı oturum kimliğiyle eşleştirildi; sitenin kendi istek başlıkları aynı oturumda kullanıldı.
- Doğrudan PC girişi, 12 hesaplık sıralı sayfalar, temkinli tempo, 429 beklemesi ve kullanıcı başlatmalı yükleme eklendi.
- Fotoğraflar çerez gönderilmeden CDN'den alınıp önbelleğe kondu. Profil sayaçları web profil sorgusundan tek tek alındı.
- Android'e belge başlangıcında web profil yanıtı gözlemleme ve aynı web oturumuyla profil bilgisi yükleme bağlandı.
- Windows x64 için Node çalışma ortamı içeren çift tıklamalı BAT/ZIP paketi yayımlandı.

## Doğrulama
- Gerçek PC oturumunda listeler, fotoğraflar, profil sayaçları ve sayfa yenilemesi sonrası kayıtlar doğrulandı.
- 45 JavaScript testi, Android birim testleri/lint/derleme ve taşınabilir Windows paket kontrolü geçti.
- Android'in yeni web oturumu akışı gerçek telefonda ayrıca doğrulanmalıdır. Instagram'ın hız sınırı devam eder; 429 alınırsa istekler durur.
