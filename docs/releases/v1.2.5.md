# Takip Atlası 1.2.5

## Ele alınan sorun
- Oturum kimliği JavaScript'ten okunamayabiliyor, büyük sayısal kimlikler yuvarlanabiliyor ve gerçek API hatası kullanıcı adı hatası olarak gizleniyordu.

## Değişiklik ve yöntem
- Android çerez deposundaki hesap kimliği tam metin değeriyle aktarıldı; güvenli olmayan sayısal kimlikler reddedildi.
- Hesap sorgularının HTTP kodları gizli değerler olmadan gösterilmeye başlandı.

## Sonraki cihaz sonucu
- Tanı mesajı iki hesap sorgusunda HTTP 400 ve detay sorgusunda HTTP 429 gösterdi. Bu sürüm hatanın nedenini görünür yaptı; doğrudan bağlantının tamamen düzeldiği anlamına gelmiyordu.
